# Доска — Канбан и Дневник · Windows

Интерфейс — файл `index.html` (тот же, что в артефакте). Python-оболочка (pywebview + системный WebView2) даёт ему окно и надёжное хранение данных.

## Что нужно один раз
- Windows 10/11, **Python 3.12 (64-бит)** с python.org, галочка «Add to PATH» / установленный `py`.
- Microsoft Edge WebView2 Runtime (в Windows 11 уже есть; если нет, программа сама откроет страницу загрузки).

## Запуск и сборка
- `run.bat` — первый раз создаст `.venv`, поставит зависимости и запустит приложение.
- `build.bat` — соберёт `dist\Doska\Doska.exe`. Режим «папка», а не «один файл»: стартует быстрее и реже ругается антивирус. Папку `dist\Doska` можно копировать целиком.

## Сборка в облаке (GitHub Actions): Python на своём компьютере не нужен
1. Зарегистрируйся на github.com (бесплатно) и создай репозиторий: **New repository**, имя, например, `doska`.
2. На странице пустого репозитория нажми **uploading an existing file** и перетащи туда **всё содержимое** распакованного архива вместе с папками `.github` и `tests`. Нажми **Commit changes**.
   Если папка `.github` не перетащилась: **Add file → Create new file**, в поле имени набери `.github/workflows/build-windows.yml` (слэши сами создадут папки), вставь содержимое одноимённого файла из архива и сохрани.
3. Открой вкладку **Actions**, выбери **Сборка для Windows** и нажми **Run workflow** (если GitHub попросит разрешить запуск, согласись).
4. Через несколько минут запуск станет зелёным. Внутри запуска внизу в разделе **Artifacts** скачай `Doska-win64`. GitHub упаковывает его ещё раз, поэтому внутри будет `Doska-win64.zip`: распакуй его, и в папке `Doska` лежит `Doska.exe`. Рядом есть `smoke-screenshot` с кадром запущенной программы из облака.
5. Чтобы получить постоянную ссылку на скачивание: **Releases → Draft a new release**, в поле метки введи `v0.1.0` и опубликуй. Сборка запустится сама и приложит архив к релизу.

При первом запуске Windows может показать синее окно SmartScreen («Windows защитила ваш компьютер»): программа пока не подписана цифровой подписью. Нажми **Подробнее → Выполнить в любом случае**.

## Что делает десктопная версия иначе
- Файл данных ведёт Python, поэтому кнопка «Выбрать файл», индикатор синхронизации и баннер браузерной версии скрыты.
- «Экспорт в JSON» открывает обычное окно «Сохранить как» Windows.
- Тема, фон, имя и плотность карточек тоже хранятся в `board.json` и восстанавливаются, даже если браузерное хранилище WebView пустое.
- Данные уходят в файл не чаще раза в секунду (и обязательно при сворачивании окна), а не после каждой буквы.

## Где данные
`%APPDATA%\KanbanDiary\`
- `board.json` — доска и дневник (пишется атомарно: временный файл → замена);
- `board.prev.json` — предыдущая версия (обновляется не чаще раза в 30 секунд);
- `backups\board-ГГГГММДД-ЧЧММСС.json` — копии раз в 10 минут, хранятся последние 30;
- `app.log` — журнал ошибок (если что-то не так, пришли его);
- `window.json` — размер и положение окна, `webview\` — служебные данные WebView2.

Если `board.json` повреждён, при запуске данные берутся из `board.prev.json`, затем из свежей копии в `backups`.

## Перенос данных из браузерной версии
В старой версии: «Ещё» → «Экспорт в JSON». В новой: «Ещё» → «Импорт из JSON». Дальше всё сохраняется само.

## Стабильность
- один экземпляр: второй запуск сообщит, что приложение уже открыто;
- встроенный сервер слушает только `127.0.0.1` и отдаёт только страницу;
- версии зависимостей зафиксированы в `requirements.txt`;
- данные записываются при каждом изменении (задержка около четверти секунды).

## Если не запускается
1. Запусти `run.bat`: окно консоли покажет ошибку.
2. Посмотри `%APPDATA%\KanbanDiary\app.log`.
3. Проверь, что Python 3.12 именно 64-битный (на 3.13+ могут быть проблемы у зависимости pythonnet).
